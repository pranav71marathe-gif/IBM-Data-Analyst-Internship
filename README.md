# IBM Data Analyst Internship Project
## Customer Churn Analysis and Prediction

### Project Overview
This project demonstrates a complete data-analytics workflow:
- Data loading and cleaning
- Missing-value handling
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Predictive analytics
- Supervised Machine Learning
- Customer segmentation using K-Means
- Visualization
- Business insights and recommendations

### Internship Learning Alignment
The project is aligned with the internship topics:
1. Kickstart Your Data Analytics Journey
2. Data Cleaning, Wrangling & Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Predictive Analytics
5. Machine Learning Basics
6. AI-Driven Insights & Visualization

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### Project Objective
To analyze customer behavior and identify patterns associated with customer churn, then use machine-learning models to predict churn and support data-driven business decisions.

### Dataset
The script can use a file named `customer_churn.csv` if supplied.

If the CSV is not available, the program automatically creates a reproducible synthetic telecom-customer dataset so that the project can still be executed for demonstration and learning.

> Important: If you submit this project as an academic/internship project, clearly mention whether your final analysis used the supplied dataset or the demonstration dataset.

### How to Run
1. Install Python 3.10 or newer.
2. Open a terminal in this project folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run:

```bash
python customer_churn_analysis.py
```

5. Open the `outputs` folder to see:
- Cleaned dataset
- EDA charts
- Confusion matrices
- Model comparison
- Customer segments
- Business insights

### Main Analysis
The project compares:
- Logistic Regression
- Decision Tree Classifier

The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

### Business Insights
The analysis examines the relationship between churn and:
- Contract type
- Tenure
- Monthly charges
- Payment method
- Technical support
- Online security
